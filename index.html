API keys

Keys are stored only in this browser's localStorage and sent only to the provider that issued them. Nothing is hardcoded.

FRED's API does not send CORS headers, so a page on GitHub Pages cannot call it directly. Either leave the FRED fields blank (the app falls back to FMP's treasury endpoint, then Alpha Vantage), or deploy the small proxy in the README and paste its URL above.
